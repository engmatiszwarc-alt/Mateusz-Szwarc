Behind The Code

I believe great games reside at the intersection of mathematical precision and expressive player feedback. Whether tuning the milliseconds of coyote-time in a high-speed platformer, architecting deterministic state rewind in C++, or writing custom HLSL screen-space post-processing shaders, I focus on tactile player delight.

Over the past 5 years, I've worked across small indie squads and solo productions. My experience spans full project lifecycles: from rapid greybox prototyping in 48-hour jams to shipping production-ready builds on Steam with optimized draw calls, automated build pipelines, and zero-leak memory management.

My Core Engineering Pillars

1. Responsiveness First: 60+ FPS baseline, instant input response, zero perceivable input lag.
2. Decoupled Architecture: Modular systems that empower designers and artists to iterate without breaking code.
3. Measurable Performance: Profile early, profile often using Unreal Insights and frame debuggers.
